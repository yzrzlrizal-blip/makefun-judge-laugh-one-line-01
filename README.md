One original joke in a single line, under 200 characters: a smartwatch counts its owner's laughs, finds zero, and suggests a personality upgrade. The program validates the line against the gate and writes it verbatim to the output file for the AI judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
